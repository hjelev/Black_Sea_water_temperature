Temperatura apei Mării Negre — Abrau-Diurso, Rusia

Situat aproape de coastă, în jurul unui lac pitoresc, Abrau-Diurso este renumit în întreaga lume pentru pivnițele istorice de vin spumant și podgoriile în terase, oferind o îmbinare rară de cultură și gastronomie lângă mare. Plaja Durso din apropiere se deschide spre Marea Neagră.

Temperatura apei mării la Abrau-Diurso, Rusia este de 20.6°C (măsurată pe 22.10.2026). Este cu 1.6°C mai caldă decât media pe 3 ani pentru această dată (19.0°C).
