Temperatura apei mării la Burgas, Bulgaria

Temperatura apei Mării Negre — Burgas, Bulgaria

Cel mai mare oraș de pe litoralul sudic bulgăresc, Burgas este un port și un centru cultural plin de viață, așezat între mare și un șir de lacuri de coastă liniștite, bogate în păsări. Elegantul parc Grădina Mării se întinde de-a lungul țărmului, spre o plajă centrală lungă și un centru pietonal animat, plin de cafenele și galerii. Orașul este principala poartă spre stațiunile din sud și oferă o atmosferă de litoral relaxată și cosmopolită.

Temperatura apei mării la Burgas, Bulgaria este de 18.9°C (măsurată pe 21.10.2026). Este cu 1.2°C mai caldă decât media pe 26 ani pentru această dată (17.7°C).
